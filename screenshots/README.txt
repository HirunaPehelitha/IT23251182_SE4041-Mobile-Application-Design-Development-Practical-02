Screenshots required by the practical sheet:

  01-Collections.png      -> output of pages Exercise01 / 02 / 03 (arrays, sets, dictionaries)
  02-Control-Flow.png     -> output of pages Exercise04 / 05 / 06 (if, switch, loops)
  03-Final-Challenge.png  -> output of the FinalChallenge page

These must be taken on your own machine so the screenshot shows your Xcode
window. Steps:

  1. Open SE4041-Practical-02.playground in Xcode.
  2. Pick a page in the navigator sidebar
     (View -> Navigators -> Show Project Navigator).
  3. Run it with Shift + Cmd + Return, then show the console with
     Cmd + Shift + Y.
  4. Screenshot the window with Cmd + Shift + 4 and save it here using the
     names above.

The exact expected console text for each page is stored in the parent folder
as <page>-output.txt if you want to compare.
